# CockroachDB × AWS Hackathon — Build with Agentic Memory

Source: https://cockroachdb-ai.devpost.com/ (retrieved 2026-08-01)

Organized by Cockroach Labs on Devpost. Online, public. Central prompt: **"Build an agentic application that uses CockroachDB as its persistent memory layer, deployed on AWS."**

## Dates (EDT)

| Milestone | Date |
|------|-------|
| Submissions open | June 30, 10:00 am |
| **Submission deadline** | **August 18, 5:00 pm** |
| Judging | August 19 – September 15 |
| Winners announced | September 21, 3:00 pm |

## Mandatory technical requirements

**At least 2 CockroachDB tools:**
- CockroachDB Cloud Managed MCP Server
- Distributed Vector Indexing
- ccloud CLI (Agent-Ready)
- Agent Skills Repo (open source)

**At least 1 AWS service:**
- Amazon Bedrock / Bedrock Agents
- AWS Lambda
- Amazon ECS/EKS
- Amazon S3
- Amazon SageMaker
- Any other AWS service

## What to submit

Required:
1. URL to a **public open source** repository (MIT or Apache 2.0 license), with README, dependencies, configuration and setup instructions.
2. URL to a **working demo**.
3. **Video of at most 3 minutes** on YouTube or Vimeo demonstrating the application.
4. Identify which CockroachDB tools were used and how they were implemented.
5. Identify which AWS services were used and how they were implemented.

Optional:
- Architecture diagram.
- Feedback on the CockroachDB tools.

## Judging criteria

No published numeric weights.

1. **Agentic Memory Design** — CockroachDB plays a meaningful, production-grade role as the agent's memory layer; usage beyond trivial queries.
2. **Technical Implementation** — software engineering quality of the integration with the CockroachDB tools.
3. **Real-World Impact** — how large the impact could be on real users or workflows.
4. **Production Readiness** — secure, observable and scalable design.
5. **Creativity & Originality** — genuinely new ideas or novel applications of the technology.
